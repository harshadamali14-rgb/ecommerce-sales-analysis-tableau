# ecommerce-sales-analysis-tableau

📊 E-Commerce Sales Analysis Dashboard (Tableau)
Project Overview

This project is an interactive Tableau dashboard built to analyze India's E-commerce Sales Dataset. It provides valuable business insights by visualizing sales performance, profit trends, customer payment preferences, regional sales distribution, product category performance, and promotional impact.

Objectives
Analyze overall sales performance.
Identify sales and profit trends over time.
Compare sales across different states.
Understand customer payment mode preferences.
Find top-performing product categories.
Analyze the impact of promotions on sales.
Dashboard Features
📈 Sales & Profit Trend Analysis
📍 State-wise Sales Dashboard
💳 Payment Mode Distribution
🛍️ Top Product Categories
🎯 Promotion Analysis
📊 KPI Dashboard
